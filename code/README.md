# Code
This folder contains Python and Bash scripts used to process data and analyze data.

## `processing`
This folder contains all scripts to process sequencing and mass spectrometry data. Raw sequencing reads are processed into tables of barcodes and counts
which can be used to compute any kind of summary statistic. 

## `analysis`
Once the data processed, we compute information footprints, expression shift matrices etc.

## `dashboards`
Create a dashboard from analyzed data to display footprints and identified binding sites using `Bokeh`.
